Vectors ×

What this practices

Everything you do to a single vector: resolving it into components, going back to a magnitude & direction, building its unit vector, and resolving it onto a set of tilted axes (an inclined plane). Vectors are written both ways — angle brackets and notation — because physics uses both and you need to read either. Angle and vector names change between problems on purpose.

Levels
1 — magnitude & angle → components.
2 — components → magnitude & direction.
3 — unit vector of a given vector (2D and 3D).
4 — resolve a vector onto axes rotated by φ.
5 — split a vector into components parallel and perpendicular to an inclined plane.
