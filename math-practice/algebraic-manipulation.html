What this practices

Isolating a variable — the single most-used skill in physics problem-solving, since every formula eventually needs to be solved for whatever you're actually looking for. Levels move from one-step linear equations, to variables on both sides, to distributing, to rearranging an actual physics formula for a target variable.

How to use

Solve the equation shown and enter the numeric value. The balance beam is just a reminder of the rule underneath all of this: an equation stays true only if you do the same thing to both sides.

Relevant moves
undo addition/subtraction first
collect the variable on one side
distribute before combining
